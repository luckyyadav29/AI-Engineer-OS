## 💡 Key Takeaways

- Python is dynamically typed — no need to declare types
- f-strings make string formatting clean and readable
- Lists = ordered, mutable collections; Dicts = key-value lookup
- Functions keep code reusable and organized
- `with open()` is the safe way to handle files
